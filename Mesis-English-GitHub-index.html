05 / GOOD TO KNOW

Frequently asked questions

What is Mesis?＋

Mesis is a client project for Minecraft Java Edition, bringing together exploration tools, personalized visuals, and interface customization. This site introduces the project and its features.

Where can I get Mesis?＋

Visit the Mesis Discord for official release announcements and download information. Direct downloads are not currently available on this site.

Which Minecraft versions are supported?＋

Check the notes for your chosen release. Before installing, make sure your Minecraft version, Fabric Loader, and required dependencies are compatible.

Can I use Mesis on any server?＋

Every server has its own rules for mods and clients. Read your server’s guidelines and only enable features where they are allowed.

How do I report an issue?＋

Report issues in the Discord community. Include your Mesis and Minecraft versions, steps to reproduce the issue, and relevant error logs. Remove private information before sharing logs.
